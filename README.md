## 💻 주요 기능

### [유저 인증]

> 3단계 회원가입 (계정 정보 → 프로필 설정 → 반려동물 등록)
> Zod 유효성 검사 (이메일 형식, 비밀번호 복잡도)
> Supabase Auth 기반 로그인/로그아웃

### [게시글]

> 다중 이미지 업로드 및 캐러셀 뷰
> 태그 추가 (산책, 간식, 목욕, 병원, 훈련, 일상, 여행, 장난감, 생일, 미용)
> 촬영 날짜 지정
> React Query 무한스크롤 피드
> 게시글 수정/삭제 (본인 게시물)

### [좋아요 · 댓글 · 북마크]

> 게시글 좋아요 / 댓글 좋아요
> 댓글 작성/삭제
> 게시글 북마크 저장 및 프로필에서 조회

### [알림]

> 좋아요, 댓글, 댓글 좋아요 시 알림 생성
> 미읽 알림 카운트 및 일괄 읽음 처리
> 알림 클릭 시 해당 게시글로 이동

### [검색]

> 태그 기반 게시글 검색 (썸네일 그리드)
> 닉네임 기반 사용자 검색

### [사용자 프로필]

> 프로필 조회 (반려동물 정보 포함)
> 게시물 날짜별 그룹핑 표시
> 북마크 탭 (본인 프로필)
> 닉네임, 자기소개, 비밀번호, 반려동물 정보 수정

### [관리자]
> 사용자 권한 관리 (approved ↔ viewer 토글)
> approved: 게시글 작성 가능 / viewer: 조회만 가능
